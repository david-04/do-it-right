# Götterfunken

These AI skills revise text to make it easier to read. Built as an alternative to Grammarly, the focus lies on simplification techniques. This includes using simple words, splitting long sentences, and converting running text to bullet point lists.

There are four skills with an increasing scope. They range from simple proofreading to a complete rewrite. Each skill extends the previous one. For example, `Restructure` also simplifies and proofreads the text.

- Proofread ([AE](american-english/proofread.md) / [BE](british-english/proofread.md))
  - Correct typos and grammatical errors only.
- Simplify ([AE](american-english/simplify.md) / [BE](british-english/simplify.md))
  - Make the text easier to read while fully preserving its structure.
  - Replace words and phrases with simpler synonyms.
  - Split long sentences into shorter ones.
  - Convert sentences with long inline enumerations to bullet point lists.
- Restructure ([AE](american-english/retructure.md) / [BE](british-english/restructure.md))
  - Improve the train of thought by regrouping and reordering sentences and paragraphs.
  - Group related information together and remove duplicate statements.
  - Sort sentences and paragraphs so that they do not reference content that only comes later.
  - Group long text into sections with headers (if it does not have headers yet) .
- Rewrite ([AE](american-english/rewrite.md) / [BE](british-english/rewrite.md))
  - Completely rewrite text that is in a poor linguistic shape (e.g. dictated text).
  - This skill works similar to `Restructure`, but changes text more aggressively.

The term "Götterfunken" is German for "spark of the gods". It comes from the 18th-century poem "[Ode to Joy](https://en.wikipedia.org/wiki/Ode_to_Joy)" by Friedrich Schiller. The AI skills will not turn text into a neoclassical poem, but aim to imbue it with enough of that divine spark to make for a pleasant reading experience.
